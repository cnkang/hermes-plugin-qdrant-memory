# Runtime 0.3.0

[English](0.3.0.md) | [简体中文](0.3.0.zh-CN.md)

本次发布新增可选的、需明确选择的 CPU Embedding provider，以及受信的
`prepare-model` 和 `setup` 命令。默认仍为 Ollama；不会因为 Ollama 或云服务
恰好不可用而自动选择 CPU。Ollama 与 OpenAI 兼容配置的默认值和身份保持不变。

CPU provider 使用多语言 MiniLM-L12-v2 模型（384 维），模型产物来自
[Qdrant 集合](https://huggingface.co/Qdrant/paraphrase-multilingual-MiniLM-L12-v2-onnx-Q)
并固定 revision，经 SHA-256 校验后支持离线启动；超过模型 128 token 上限的
输入会被拒绝。依赖集合为可选的 `local` extra；准备好的模型缓存约 252 MB。

`setup` 只初始化全新的私有 embedded profile，保留写入者所有权与恢复语义，
并在重复调用时拒绝配置变更；`prepare-model` 负责获取并校验模型产物。
中断的准备过程不再阻塞重试，锁竞争会报告独立的 busy 状态。

在独立的 Python 3.11+ 环境中安装：

```bash
pip install 'hermes-plugin-qdrant-memory[mcp]==0.3.0'
qdrant-memory --home /path/to/profile doctor
```

无需数据迁移。schema-v1、ID、作用域、embedding 指纹、显式写入和账本恢复
与 Runtime 0.2.2 保持兼容。升级时保留相同的 profile、collection 和
embedding pipeline。Hermes 原生安装使用插件管理器；PyPI 发布不会更新
单独审核的 Plugin Catalog 固定版本。

CI 在 Linux、macOS、Windows 的 Python 3.11 和 3.14 上验证；可选 CPU Embedding
作业会在三个系统上准备固定模型产物并运行真实的离线模型验收。这些检查不代表
所有实际 agent 客户端或 embedding 服务均已通过验证。

MCP 发行包固定依赖经过验证的 Runtime revision，Runtime 0.3.0 的更新随后在
MCP 仓库发布。Skill 0.2.6 提供安装和使用指引，不包含运行时。

每个目标仍只允许一个写作者。独立 MCP 只执行显式操作；自动提取与预取
仍属于 Hermes 生命周期能力。
