# Runtime 0.2.0

This version supplies the first PyPI release of `hermes-plugin-qdrant-memory`.
It includes the previously merged standalone CLI and optional official Python
MCP SDK adapter. Publishing uses protected GitHub Actions and PyPI Trusted Publishing.

Install after publication with `pip install 'hermes-plugin-qdrant-memory[mcp]==0.2.0'`.
Run `qdrant-memory --home /path/to/profile init`, then
`qdrant-memory --home /path/to/profile mcp`. Configure the profile and embedding
service first; see [standalone](../standalone.md).

The four explicit MCP tools share the original Runtime. Automatic extraction and
prefetch remain Hermes lifecycle capabilities. No Hermes installation is needed
for standalone CLI/MCP. This release preparation changes version metadata and
publishing only: provider interfaces, data schema, IDs, migrations and recovery
behavior retain the merged implementation.

PyPI Trusted Publisher settings: owner `cnkang`, repository
`hermes-plugin-qdrant-memory`, workflow `publish.yml`, environment `pypi`.
Only version tags on commits contained in main are eligible. The publishing job
checks built distribution hashes against any existing PyPI version before a
retry skips upload; a conflicting existing version fails closed.
