# Runtime 0.6.1：持久生命周期重试

此补丁版本为已持久接收的事件新增经过认证的 Owner lifecycle retry 操作。Owner
会将不可变事件计划与 receipt 一起保存。重试只需要事件 ID；Owner 复用已保存计划，
返回状态，不返回候选内容。

这样，原生 harness 适配器在响应丢失或进程重启后，可以恢复已接收轮次，而无需把
候选文本保存在 harness session log 中，也无需重新提取轮次。适配器和 Owner 仍使用
同一设备 grant、事件标识和 receipt。

Runtime 0.6.0 的功能、存储格式和安全默认值保持不变。现有 lifecycle endpoint 仍需
显式启用。

## 安装此版本

安装前确认 PyPI 已公开 0.6.1：

```sh
python -m pip install 'hermes-plugin-qdrant-memory[mcp]==0.6.1'
qdrant-memory --help
```

此命令安装无需 Hermes 的独立 CLI 和 MCP 基础组件。CPU embedding 需额外安装
`local` extra，并明确批准模型准备。记忆操作前先配置私有 profile，参见
[独立运行指南](https://github.com/cnkang/hermes-plugin-qdrant-memory/blob/v0.6.1/docs/standalone.md)
和 [CPU 设置](https://github.com/cnkang/hermes-plugin-qdrant-memory/blob/v0.6.1/docs/local-embedding.md)。
