# Runtime 0.6.0：可迁移的 Codex 记忆

此版本新增 Codex v1/v2 语义记忆的显式检查与导入，以及可阅读、可验证的
JSON/Markdown 交接包。原生来源、Qdrant 数据与插件安装相互独立；卸载插件
不会删除已保存的记忆和导出文件。

操作前请查看已安装版本的 `qdrant-memory codex --help`。提交导入前先预览，
并检查跳过原因。凭据形状内容、代码围栏、原始对话及不支持的文件不会通过此
适配器进入语义记忆。

交接验证核对记录 ID、正文、作用域、大小和校验和，不会把校验通过表述为
Codex 已经采用这些记忆。目的端确认实际采用前，状态仍为 `HANDOFF_PENDING`；
此版本不提供向原生记忆库批量回写的能力。

macOS/Linux 使用目录描述符锚定的 no-follow 读取。Windows 使用经检查的原生
句柄，拒绝 reparse point 和远程卷，并要求新建交接目录具备持久化的私有 ACL。
文件系统无法提供必要保证时拒绝操作。

显式模型准备为每个文件保留 15 分钟下载窗口，仍校验大小、固定哈希并原子发布
缓存；未完成或超时的下载不会被标记为可用。
可取消的截止时间覆盖连接、响应头和流式正文读取，持续小片段也不能绕过。
超时后关闭网络资源、清理临时文件并释放准备锁，再允许重试。

Codex/Ollama Cloud 验收仅使用合成数据和本地 embedding 夹具，验证 harness 与
工具行为，不代表验证了 embedding 模型推理。Runtime、Python MCP、托管启动器
和 Skills 分别发布并保留独立固定引用；发布 Runtime 不会自动升级它们，也不会
发布 Codex Marketplace 候选插件。
