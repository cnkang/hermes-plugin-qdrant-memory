# Runtime 0.5.5

[English](0.5.5.md) | [简体中文](0.5.5.zh-CN.md)

此补丁将可选的本地 CPU embedding 依赖升级到上游 FastEmbed 0.9.1，并移除了为兼容 Pillow 13
而临时构建的、只修改元数据的 wheel。

## 变更

- `local` extra 及其锁定环境改用官方 FastEmbed 0.9.1 发行包。
- 移除临时兼容 wheel 构建脚本和对应测试。推理模型、模型 revision、维度和向量校验保持不变。

## 升级与数据兼容性

按常规的固定版本升级流程操作。默认 embedding provider 与 remote extra 不变。本版本不改变
collection schema、point identity、scope、归属规则、配置 schema、公共工具 schema 或 MCP 调用接口。
所选 embedding pipeline fingerprint 兼容时，现有记忆无需迁移。较早的本地 CPU profile
使用 FastEmbed 0.9.0，其指纹不同于本版本的 0.9.1 管线；切换前可能需要重新嵌入到新的
profile 和 collection。参见 [Runtime 0.6.0 CPU 迁移说明](0.6.0.md)。

## 安装

运行固定版本的安装命令前，请先确认 Runtime 0.5.5 已在
[PyPI](https://pypi.org/project/hermes-plugin-qdrant-memory/0.5.5/) 可用。

```sh
python3 -m venv /absolute/path/runtime-env
/absolute/path/runtime-env/bin/python -m pip install 'hermes-plugin-qdrant-memory[mcp]==0.5.5'
```

通用 MCP 发行包与托管启动器各自选择精确的 Runtime 依赖，与本包分别发布。
