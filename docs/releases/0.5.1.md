# Runtime 0.5.1

[English](0.5.1.md) | [简体中文](0.5.1.zh-CN.md)

This patch fixes the protected Owner recovery path. A two-device acceptance run
with OpenCode and Pi found the defects. No schema, collection identity or
credential format changed.

## Fixed

- `retry` accepts `--policy` and admits an enrolled destination. The command
  failed closed before this release, so retained work could not be requeued.
  The explicit policy keeps the invocation-directory rule and the private-state
  checks. Without the flag the refusal is unchanged.
- A relative `--home` now resolves once at the CLI boundary. `verify`, `list`,
  `stats`, `doctor` and `retry` behave like the absolute path.
- An unresolvable `--home` now returns the sanitized JSON error instead of a
  traceback.
- The loopback HTTPS listener reuses its port on POSIX. A normal stop followed
  by an immediate restart no longer fails with an address-in-use error. Windows
  keeps the socket option off, because that platform treats it as permission to
  share a live port.

## Install

Check that Runtime 0.5.1 is available on [PyPI](https://pypi.org/project/hermes-plugin-qdrant-memory/0.5.1/)
before running the versioned package command.

```sh
python3 -m venv /absolute/path/owner-env
/absolute/path/owner-env/bin/python -m pip install 'hermes-plugin-qdrant-memory[remote]==0.5.1'
```

For local stdio MCP only, select `[mcp]`. For offline CPU embeddings, also
select `[local]`.

## Upgrade

Stop the Owner before the upgrade. Back up the Qdrant data, the Ledger, the
device registry, the protected claim and the policy as one consistent set.
This release adds no migration step. Start the new Owner against the same
profile.

For an enrolled destination, run the recovery command from the directory that
holds the policy. Pass an absolute `--home`.

```sh
qdrant-memory --home /absolute/path/owner retry --policy ./owner-policy.json
```

## Validation and limits

The local suite passed 1076 tests with 0 failures and 11 gated skips. The
[cross-device acceptance record](../validation/cross-device-opencode-pi-2026-10.md)
lists the matrix, the evidence and the open limits. Release CI tests the
installed wheel and the source archive.

The limits of 0.5.0 remain. There is no distributed multi-writer mode,
automatic failover, OAuth browser enrollment or group administration UI.
A deterministic extraction failure still blocks every writer until an operator
repairs the model and retries.
