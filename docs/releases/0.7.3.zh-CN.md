# Runtime 0.7.3：验证升级恢复检查点

Runtime 0.7.3 加强了操作者的升级流程。已保存的 plan 会绑定到 profile 本地 Ledger
写入水位；只有 Qdrant 快照和复制的 SQLite Ledger 都通过验证后，才会发布 embedded
恢复点。

## 相比 0.7.2 的变化

- plan 会记录本地 Ledger 写入水位，包括已提交写入和 destination reset epoch。
  `apply` 与 `resume` 会在持有 profile `WriterLease` 时再次检查。即使更新保留了
  point ID 和 point count，本地已提交更新仍会使 plan 过期。如果之后 row ID 重复，
  destination reset 也会使旧边界失效。
- 发布 embedded 恢复点前，Runtime 会按计划中的 point count 与 embedding fingerprint
  检查复制的 Qdrant store，并验证复制的 SQLite Ledger 及其保存的水位。无效 marker
  identity、损坏的 Ledger 文件和不匹配的恢复元数据都不会被接受为恢复点。
- 若验证复制的 Ledger 时 profile 文件系统空间不足，操作会停止，并保留可恢复的检查点，
  供同一 plan 后续重试。释放空间后重试；不要仅为绕过验证失败而替换有效 plan。
- 未解决的 Shared Owner receipt 或未完成的 shared request 仍会阻止维护操作，直到现有
  Owner 恢复流程完成。

## 升级流程

规划前停止所有能够访问目标的 writer。运行
`qdrant-memory --home /path/to/profile upgrade plan`，并审阅返回的目标、collection、
point count 和 embedding identity。只应用该已保存计划：`upgrade apply --plan PLAN_ID`。

使用只读命令 `upgrade status` 检查已保存计划。仅当 plan 未过期且其已验证恢复点仍可用时，
才使用原 ID 续跑中断的 plan。规划后的本地写入（包括更新既有 point）或已完成的
destination reset 都会使 plan 过期。运行 `upgrade plan --replace`，归档旧 plan 和恢复引用，
并在新的停写边界创建检查点。不要修改或删除旧检查点来让它看起来可以复用。

## 保护范围、兼容性与恢复限制

水位仅观察此 profile 本地 Ledger 记录的已提交写入。它无法观察通过其他 Runtime profile、
其他主机、其他凭据或直接 Qdrant 客户端完成的写入。`WriterLease` 只协调同一 profile 和
destination 中会配合的本地 writer；它不是分布式锁。对于 Qdrant Server 和 Cloud，请隔离所有
外部 writer，并在升级前通过服务商在新的停写边界创建快照。

本次发行不改变 dense 检索默认值、collection identity、point ID、payload、embedding 维度或
embedding fingerprint。已有数据保留原处，无需数据迁移、重新嵌入或重建索引。四个显式 MCP
工具、现有授权和作用域规则保持不变。普通 MCP 操作仍不会自动提取对话，也不会暴露维护命令。

应用回退表示重新安装旧版 Runtime；这不意味着旧 Qdrant 引擎可以安全打开由新引擎写入的数据。
恢复到某个检查点会丢弃该检查点之后的写入。它不能替代外部 writer 协调或服务商自己的备份。

## 兼容性

Runtime 0.7.3 保持 Python 3.11+ 以及 MCP Python SDK 1.x、2.x 支持。Hermes 最低版本仍以原生
manifest 声明为准。请参见[验证记录](../validation.md)，了解本候选版已运行的检查及仍未验证的
环境相关检查。

## 安装

安装到私有环境前，请先在 [PyPI](https://pypi.org/project/hermes-plugin-qdrant-memory/0.7.3/)
确认该版本已经公开：

```sh
python -m pip install 'hermes-plugin-qdrant-memory[mcp]==0.7.3'
```

已有 destination 请先审阅 `upgrade status` 和 `upgrade plan`。不要使用 editable checkout 或
尚未公开的构件作为公开安装验证证据。
