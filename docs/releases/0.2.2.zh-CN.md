# Runtime 0.2.2

[English](0.2.2.md) | [简体中文](0.2.2.zh-CN.md)

此补丁支持 MCP Python SDK 1.x 和 2.x。SDK 1.x 使用装饰器注册处理器，
SDK 2.x 使用构造函数回调。适配器兼容两种 API，保留四个固定作用域工具、
输入验证和脱敏错误。可选依赖为 `mcp>=1.30,<3`，仅使用 CLI 时无需安装。

在独立的 Python 3.11+ 环境中安装：

```bash
pip install 'hermes-plugin-qdrant-memory[mcp]==0.2.2'
qdrant-memory --home /path/to/profile doctor
```

需要指定 SDK 主版本时，将 Runtime 与 `mcp>=1.30,<2` 或 `mcp>=2,<3`
一起安装，无需启用预发布版本。MCP 发行包 0.1.2 固定依赖此 Runtime。
Skill 0.2.5 提供安装和使用指引，不包含运行时。

无需数据迁移。schema-v1、ID、作用域、embedding 指纹、显式写入和账本恢复
与 Runtime 0.2.1 保持兼容。升级时保留相同的 profile、collection 和
embedding pipeline。Hermes 原生安装使用插件管理器；PyPI 发布不会更新
单独审核的 Plugin Catalog 固定版本。

CI 在 Linux、macOS、Windows 的 Python 3.11 和 3.14 上验证两种 SDK 主版本，
覆盖官方 stdio 协议及显式写入。这些检查不代表所有实际 agent 客户端或
embedding 服务均已通过验证。

每个目标仍只允许一个写入者。独立 MCP 只执行显式操作；自动提取与预取
仍属于 Hermes 生命周期能力。
