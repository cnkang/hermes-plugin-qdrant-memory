# Runtime 0.5.4

[English](0.5.4.md) | [简体中文](0.5.4.zh-CN.md)

此补丁是可维护性版本。它保持 Runtime 0.5.3 的对外行为不变，让代码更容易审计和扩展。

## 变更

- Provider 生命周期、CLI 维护路径、Ledger、迁移流程、远程网关与共享服务中的长函数改为
  委派给具名辅助函数。每个辅助函数保持原有的校验顺序、异常类型与错误消息。
- Provider 记录初始化失败后会重新抛出原始异常。清理路径捕获 `Exception`，
  因此 `SystemExit` 与 `KeyboardInterrupt` 会照常向上传播，不再被吞掉。
- 重复出现的运维提示与配置提示改为模块常量。后续修改措辞只需改一处。
- 测试断言各自给出独立的失败信号。`pytest.raises` 块内只保留一次调用，
  准备阶段的故障不会被误报为预期契约违规。

## 升级与数据兼容性

按常规的版本固定升级流程操作即可。本版本不改变 collection schema、point identity、
Ledger schema、scope 或归属规则、配置 schema、公共工具 schema、MCP 调用接口，
也不改变最低 Hermes 版本。无需迁移数据，现有记忆不会被重写。

## 安装

运行固定版本的安装命令前，请确认 Runtime 0.5.4 已在
[PyPI](https://pypi.org/project/hermes-plugin-qdrant-memory/0.5.4/) 可用。

```sh
python3 -m venv /absolute/path/runtime-env
/absolute/path/runtime-env/bin/python -m pip install 'hermes-plugin-qdrant-memory[mcp]==0.5.4'
```

通用 MCP 发行包与托管启动器各自选择精确的 Runtime 依赖，与本包分别发布。
