# Runtime 0.5.5

[English](0.5.5.md) | [简体中文](0.5.5.zh-CN.md)

This patch updates the optional local CPU embedding dependency to the upstream
FastEmbed 0.9.1 release. It removes the temporary metadata-only compatibility
wheel that was used while the upstream package was incompatible with Pillow 13.

## Changed

- Pin the `local` extra and its locked environment to the official FastEmbed
  0.9.1 distribution.
- Remove the temporary compatibility wheel builder and its tests. The inference
  model, model revision, dimensions and vector validation remain unchanged.

## Upgrade and data compatibility

Use the normal versioned upgrade procedure. The default embedding provider and
remote embedding extra are unchanged. No collection schema, point identity,
scope, ownership rule, configuration schema, public tool schema or MCP call
interface changed. Existing memories need no migration when the selected
embedding pipeline fingerprint remains compatible. Earlier local CPU profiles
that used FastEmbed 0.9.0 have a different fingerprint from this release's
FastEmbed 0.9.1 pipeline; they may require re-embedding into a new profile and
collection before switching. See the [Runtime 0.6.0 CPU migration notes](0.6.0.md).

## Install

Check that Runtime 0.5.5 is available on
[PyPI](https://pypi.org/project/hermes-plugin-qdrant-memory/0.5.5/) before
running the versioned package command.

```sh
python3 -m venv /absolute/path/runtime-env
/absolute/path/runtime-env/bin/python -m pip install 'hermes-plugin-qdrant-memory[mcp]==0.5.5'
```

The generic MCP distribution and managed launcher select their own exact
Runtime dependency. They are released independently from this package.
